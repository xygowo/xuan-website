隱私權政策

這份政策說明璇（Xuan）會處理哪些資料、為什麼需要、放在哪裡、會傳給誰。範圍、位置與對象都寫在下面。

01適用範圍

本政策適用於 Discord 機器人「璇（Xuan）」及其官方介紹網站。璇只在伺服器頻道中運作，不處理私人訊息（DM），也不會主動加入伺服器或發起對話。

本政策不適用於 Discord 平台本身的資料處理，也不適用於你透過璇點開的第三方網站。那些服務有自己的隱私政策。

02我們處理的資料

2.1 頻道訊息

為了讓璇理解上下文，伺服器頻道中的每一則訊息（包含沒有提及他的訊息、其他機器人的訊息）都會被記錄到該頻道的短期記憶，內容包括：

  • 訊息文字內容與發送時間。
  • 發送者的使用者 ID、使用者名稱與伺服器暱稱。
  • 訊息 ID、頻道 ID 與伺服器 ID。
  • 訊息中附帶的附件檔名、類型與連結。

請注意即使你沒有呼叫璇，你在該頻道說的話仍會進入短期記憶，並在之後被用來理解對話。若你不希望訊息被處理，請在沒有璇的頻道發言，或請管理員調整權限。

2.2 附件與圖片

你上傳的圖片會以 Base64 形式傳送給語言模型進行理解，單次請求最多包含三張近期圖片。圖片會暫存在執行 Bot 那台機器的快取目錄，供短期記憶重讀；純文字類型的附件（如 .txt、.md、.json）會被讀取內容作為參考。

其他類型（影片、音訊、壓縮檔等）目前只會記錄檔名與類型，不會解析內容。

2.3 記憶與筆記

  • 個人印象記憶：你主動提及、或璇判斷值得記住的內容（喜好、近況、希望被稱呼的名字），以伺服器與你的使用者 ID 為鍵保存。
  • 頻道共享筆記：該頻道的主題、術語、約定與進度，以 Markdown 形式保存，頻道成員共用。
  • 提醒事項：提醒內容、觸發時間、目標使用者 ID。

2.4 使用紀錄

  • 指令使用紀錄與功能操作結果（例如筆記更新、記憶整理）。
  • 語言模型的 token 用量（輸入與輸出數量），用於 /xuan_energy_check 與成本監控。
  • 系統日誌：錯誤訊息、啟動狀態、外部工具呼叫結果。日誌可能包含頻道 ID 與使用者 ID，但不作為行銷用途。

2.5 伺服器設定

管理員設定的說話風格、社群連結預覽開關、遊戲狀態通知頻道與身分組標記等偏好設定。

03處理目的

  • 生成回覆：把訊息、記憶與筆記組成上下文，交給語言模型產生回應。
  • 維持對話連貫：透過短期記憶與個人印象，讓璇記得前面聊過什麼。
  • 執行你要求的動作：設定提醒、查詢資料、更新頻道筆記、抽選。
  • 除錯與維護：分析錯誤日誌、修復功能、避免濫用。
  • 成本管理：統計 token 用量，避免模型額度被異常消耗。

我們不會將你的資料用於廣告投放、出售、建立跨網站的行為側寫，也不會用來訓練我們自己的模型。

04保存位置與期限

璇的資料保存在執行 Bot 的伺服器本機檔案系統，不使用雲端資料庫。主要位置包括：

  • data/personal_memories/：個人印象記憶，依伺服器與使用者 ID 分層存放。
  • data/channel_memories/：頻道共享筆記。
  • data/reminders.json：提醒事項。
  • data/usage_logs/：token 用量紀錄（JSONL）。
  • data/stm_image_cache/：圖片暫存快取。

保存期限依資料類型而不同：

  • 頻道短期記憶：僅存在於執行中的記憶體，最多保留最近 30 則訊息與 15 則對話，超出即淘汰；重新啟動後不保留。
  • 個人印象與頻道筆記：持續保存，直到你或擁有者要求刪除，或該伺服器停止使用本服務。
  • 提醒事項：觸發並發送後，該筆提醒即從清單中移除。
  • 用量紀錄：保留供月度統計與成本核對。
  • 備份檔：每日 04:00 打包一次，保留 30 天。

執行期資料會每日備份到私有的雲端硬碟空間。備份檔為未加密的壓縮檔，僅擁有者可存取，且不包含 API 金鑰與授權憑證。

05分享對象

我們不會出售你的個人資料。資料僅在下列情況被傳送或揭露：

  • Discord：所有訊息與互動本身即透過 Discord 傳輸。
  • Google Cloud Vertex AI：主要語言模型，接收對話內容、記憶摘要與圖片。
  • OpenAI 相容端點（備援）：當主要模型不可用或額度用盡時，同樣的內容會傳送至備援模型供應商。
  • 外部搜尋服務（Exa MCP）：僅傳送搜尋關鍵字與你要他讀取的網址，不傳送完整對話。程式另保留 Google Custom Search 介面，未啟用時不會呼叫。
  • 公開連結預覽網域（如 fxtwitter、kkinstagram、vxthreads、vxbilibili）：當頻道啟用社群連結替換時，僅傳送該則公開貼文的網址。
  • 遊戲狀態 API（MapleStatus）：僅查詢公開的伺服器狀態，不傳送任何使用者資料。
  • 雲端硬碟備份空間：存放每日備份檔。
  • 法律要求：當依法令、司法或主管機關要求時，我們可能揭露必要資料。

開發者在維護、除錯或回應你的請求時，可能存取已保存的資料。存取僅限於完成該目的所需的範圍。

06我們不做的事

  • 不販售、出租或以行銷為目的交換你的資料。
  • 不將對話內容公開展示或提供給其他使用者查詢。
  • 不跨伺服器比對同一使用者的私人記憶（個人印象以伺服器與使用者 ID 隔離，僅在該使用者出現的伺服器中運用）。
  • 不要求你提供密碼、驗證碼或任何 Discord 帳號憑證。
  • 不在私訊中收集資料，因為璇不處理私訊。

07你的權利

你可以透過下列方式掌握與處理自己的資料：

  • 查看頻道記憶：在頻道輸入 /history，可看到目前的短期記憶摘要與附件索引。
  • 查看用量：使用 /xuan_energy_check 查看自己與伺服器的 token 用量。
  • 要求刪除：透過第 11 條的聯絡方式提出，我們會刪除與你使用者 ID 相關的個人印象與可識別紀錄；頻道筆記若含你的發言，會視情況改寫或移除。
  • 停止收集：請管理員將璇移出伺服器，或撤銷他在特定頻道的讀取權限。
  • 更正資訊：若記憶內容有誤，可直接告訴璇更新，或請擁有者協助修正。

提出請求時，請附上你的 Discord 使用者 ID 與所在伺服器，以便我們定位資料。我們會在合理時間內處理，通常為數個工作日。

08兒童與未成年人

本服務不針對 13 歲以下兒童，我們不會刻意收集其個人資料。若你發現有未滿 13 歲的使用者正在使用本服務，請通知我們，我們會移除相關資料並停止該伺服器的存取。

若你介於 13 至 18 歲之間，請在監護人知情的情況下使用，並避免在對話中揭露真實姓名、住址、學校或聯絡方式。

09資訊安全

我們採取的措施包括：API 金鑰僅存放於伺服器環境變數、資料檔案不進入公開版本控制、備份存放於私有雲端空間且僅擁有者帳號可存取、外部網頁內容一律視為不可信資料以避免提示注入。

然而，沒有任何網路傳輸或電子儲存方式能保證百分之百安全。若發生影響你權益的資料外洩，我們會在確認後於機器人所在的伺服器公告，並說明影響範圍與處置方式。

請不要主動在對話中提供密碼、身分證號、金融帳號或其他敏感資訊；璇不需要這些資料，也無法保護它們。

10政策變更

當功能調整導致資料處理方式改變（例如新增第三方模型、改變保存期限），我們會更新本頁並修改頁首日期。重大變更會另外在機器人所在的伺服器公告。

變更後繼續使用本服務，視為你接受更新後的政策。若不同意，請停止使用並將璇移出伺服器。

與隱私相關的查詢、刪除請求或安全通報，請透過 Discord 聯絡擁有者：

  • Discord：xygowo

若你的請求涉及其他成員的資料，我們會在保護他人隱私的前提下處理，並可能請你補充說明以確認身分。
