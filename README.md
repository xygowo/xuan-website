# xuan-website

璇（Xuan）的品牌介紹網站：`index.html`、`privacy.html`、`tos.html`，純靜態 HTML/CSS/JS。

- 正式網址：<https://xuan.xygowo.com/>
- 部署：Cloudflare Pages 自動從 GitHub `main` 建置，push 後即上線。
- 設計語彙：只繼承 Xuan 設計系統的 `colors` 與對比規則，細節見上層 repo 的 `docs/web.md` §11。
- 分享卡：`assets/img/og-cover.jpg`（1200×630），`og:url` / `og:image` 使用正式網域絕對路徑。
